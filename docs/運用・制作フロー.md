## 全体フロー概観

```
自治体選定 → データ収集 → JSON作成 → 実装 → GitHubへpush → Cloudflare Pagesに自動デプロイ
    ↑                                                              ↓
    └──────────────── トラフィック実績 → 自治体営業 ────────────────┘
```

フェーズは2段階。

- **Phase 1（ゲリラ期）** 自分でサイトを運営し、アクセスを稼いで実績を作る ← いまここ
- **Phase 2（SaaS期）** 実績を武器に自治体と契約、月額収益へ移行

**2026-07-24追記（`太平さんの目的メモ.md`参照）**: 上記2フェーズは「自治体との関係構築」の時間軸であり、これとは別に「収益化の検証」トラックを並走させる。AdSense申請・アフィリエイト審査など、トラフィックを待たずに今から着手できる“配管工事”はPhase 1のうちに前倒しで進めてよい（意味のある金額になるかはトラフィック次第だが、仕組みそのものの整備は待つ理由がない）。また、新規自治体の追加ペースは「競合より速く」ではなく「型ができてから複製する速さ」を優先する方針とした（正確さ・コンテンツの厚みという差別化軸を守るため）。
