## 全体フロー概観

```
自治体選定 → データ収集 → JSON作成 → 実装 → GitHubへpush → Cloudflare Pagesに自動デプロイ
    ↑                                                              ↓
    └──────────────── トラフィック実績 → 自治体営業 ────────────────┘
```

フェーズは2段階。

- **Phase 1（ゲリラ期）** 自分でサイトを運営し、アクセスを稼いで実績を作る ← いまここ
- **Phase 2（SaaS期）** 実績を武器に自治体と契約、月額収益へ移行

**2026-07-24追記（`太平さんの目的メモ.md`参照）**: 上記2フェーズは「自治体との関係構築」の時間軸であり、これとは別に「収益化の検証」トラックを並走させる。AdSense申請・アフィリエイト審査など、トラフィックを待たずに今から着手できる“配管工事”はPhase 1のうちに前倒しで進めてよい（意味のある金額になるかはトラフィック次第だが、仕組みそのものの整備は待つ理由がない）。また、新規自治体の追加ペースは「競合より速く」ではなく「型ができてから複製する速さ」を優先する方針とした（正確さ・コンテンツの厚みという差別化軸を守るため）。

## STEP 1｜自治体の選定

**担当：自分（AIが補助）**

| 条件 | 理由 |
|------|------|
| 人口 3〜10万人 | 大きすぎず、競合が少ない |
| 既存ごみアプリなし | さんあ〜る等が未導入の自治体を狙う |
| PDFまたはWebのみでアプリ未対応 | データ取得しやすい |
| 埼玉・東京近郊 | 将来の営業訪問を想定 |
| 転入超過率・若年層比率が高い | 「引っ越したばかりでルールを知らない新住民」が常に一定数いる＝検索需要が絶えない。Phase 2では役所への問い合わせ削減という営業トークにもなる（2026-08-26追記） |
| 単身世帯率・賃貸集合住宅率が高い | 戸建て中心の地域より住民の入れ替わりが速く、ルールを覚え直す需要が発生しやすい。ただし大型タワーマンションは建物独自の24時間ゴミ置き場・管理ルールに依存しがちで市の収集カレンダーへの依存度が下がるため、狙うべきは「賃貸・中小規模の集合住宅の比率」であって「マンション面積の総量」ではない（2026-08-26追記） |

- **競合の実態がより詳細に判明**：神奈川県・千葉県の転入超過上位自治体（海老名市・平塚市・茅ヶ崎市・秦野市・八千代市・市川市等）を個別に競合調査したところ、「さんあ〜る」「ごみスケ」だけでなく、**「ごみサク」（gomisaku.jp）という品目検索特化のWeb辞典サービスが想定より広く普及している**ことが判明（従来は東京多摩地域の東久留米市等でのみ確認していたが、神奈川県中南部・千葉県北西部にも展開）。ごみサクはアプリと異なり検索エンジンに直接インデックスされるWebページのため、ごみニコの主戦場（Google検索経由の流入）と直接競合する。**「自治体独自アプリの有無」だけでなく「品目名で検索できる公式Web辞典・ごみサク等の有無」を競合判定の主軸に見直す必要がある**。
- **「Trash Lens」等の汎用AI写真判定アプリは実質的な競合ではないと判断**：検索するとほぼ全市区町村で「【〇〇市にも対応！】未来のゴミ分別アプリ Trash Lens」という同一パターンのページがヒットするが、これは自治体非公式の全国対応汎用サービス（自治体との提携なしに全市区町村向けページを機械的に量産していると見られる）。同様に「生活ガイド.com」「くらしぽーたる」「不用品回収業者のまとめサイト」等も日本全国どの自治体でも一律にヒットする低品質コンテンツであり、真の競合とはみなさない（これらは既存の追加済み自治体でも同様に検索結果に混ざっている背景ノイズ）。
