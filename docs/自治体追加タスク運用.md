# 自治体追加タスク運用

新規自治体追加の「事前調査 → 作成」を分担するための運用メモ。事前調査回は一次資料が取れるかだけを判定し、データJSONは作らない。作成回は「取得可」の候補から着手する。

## 判定基準

- **取得可**：①地区別の収集曜日が分かる資料のURLと、②品目分別表の形式が確認できたもの。収集曜日が推測でしか分からないものは取得可にしない。
- **取得不可**：理由を書く（再試行は1自治体あたり2回まで）。直近14日以内は再調査しない。
- **未確定**：資料の一部は確認できたが、①②のどちらかが未確認のもの。
